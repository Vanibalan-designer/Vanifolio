Board Sync

An agent that reads my own biweekly update and reconciles it against my Jira board — so the board stops lying about what I actually did.

Role Senior Product Designer
Built with Claude Code, Gmail & Jira MCP
Status In active use, biweekly
01

Problem

Every two weeks I wrote a biweekly update by hand, then separately went into Jira to update tickets, fix statuses that had drifted, link them to the roadmap, and cross-check what other teams shipped that touched my work.

Four disconnected chores that all described the same two weeks of work — done manually, from memory, usually a day late.

02

Why I needed it

Every cycle it was the same reconciliation, done by hand: read my own update, find the right ticket, fix whatever had drifted, link it to the roadmap. Doing it manually meant it happened late, or not at all — and small things slipped through, like a teammate's update flagging a delay risk to a ticket I owned, simply because nobody was reading closely enough, every single time.

03

Solution

Board Sync is a skill that does that reconciliation directly: it reads my biweekly update from Gmail, matches each line to the right Jira ticket, posts the update, fixes the status if it's lying, links it to the roadmap, and flags what still needs my judgment.

I still make every call — what ticket a vague line belongs to, whether to create a new one. The agent proposes and asks; I decide.
